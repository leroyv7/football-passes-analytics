# Football Passes Analytics

A project for ULMS744: Sports Data Analytics in Practice

This project analyses elite European, heavily possession-based teams in the 2015/16 domestic season and what vertical lanes on the pitch they used the most when it came to passing the ball and progressing it up the pitch. 

This project compares selected teams from the Bundesliga, Premier League, Serie A, Ligue 1 and La Liga.

Tools used: R, tidyverse, StatsBombR, ggsoccer, ggplot2, Shiny and Shinylive.
